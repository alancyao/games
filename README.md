# Games

Browser games, each built by an AI model from one prompt. Alan Yao plays every build and rates it out of 10. The catalog is at [www.alanyao.com/games](https://www.alanyao.com/games/).

Every file in this repository is generated by a publish script: the catalog page, the gameplay clips and the built games. A change made here by hand is overwritten the next time the site is published.
